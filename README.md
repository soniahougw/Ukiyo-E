For my final project in Spring 2026 semester’s UI/UX course, I designed an interactive bilingual website titled WHEN THE WORLD IS UKIYO-E. Building on the historical context of ukiyo-e, the project aims to reintroduce this art form to contemporary audiences through a fresh and engaging perspective. Using vibrant colors and a playful user interface, the website reinterprets themes once portrayed by ukiyo-e artists, including scenes from everyday life, and iconic landscapes. By translating the spirit of the “floating world” into a digital experience, the project offers users a new way to engage with ukiyo-e within a modern context.
